# Conference reviewer handbook — contents

## How to use this book

Start with [the skill entry point](../SKILL.md) for routing and essential gates.
Read Chapter 1 when starting a review, then consult the chapters relevant to the
current stage. The chapter order explains the process; it does not mandate a
fixed reading order, pass count, or loading every file. For public training use
the relevant chapters directly. For confidential submissions, resolve the
permission gate before inspecting content.

H = hard rule; V = applicable venue requirement; S = adaptable default. The
classification lives in Chapter 1; examples and chapter numbering do not create
extra rules. This handbook can be installed independently of its sibling skill.

## Appendices — consult separately

- [A. Sources and verification limits](appendices/sources.md): provenance and access history.
- [B. Development evaluation protocol](appendices/evaluation.md): testing the skill, not conducting an ordinary review.
- [C. Answer key](appendices/evaluation-key.md): evaluator-only material; keep out of blinded review contexts.
- Development datasets: [scientific cases](../assets/evaluation-cases.jsonl) and [venue scenarios](../assets/venue-scenarios.jsonl). These are not manuscript evidence.

The evaluation has not been run. Structure and package checks do not establish
scientific review performance. During blinded evaluation, exclude the worked
example, evaluation appendices, answer key, and other cases as the protocol requires;
do not follow this contents page to access them in the tested inference context.
